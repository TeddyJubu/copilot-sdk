The 17 October 2026 beta is published as **`@yourgpt/llm-sdk@2.6.0-beta.3`** and **`@yourgpt/copilot-sdk@2.5.1-beta.3`**. These versions use npm's `beta` tag. The beta publication left the `latest` tags unchanged. For the prepared stable promotion, whose npm publication is separate, see the [2.6.0 upgrade guide](/docs/release-2-6).

## Install the beta

Pin both packages when validating an upgrade:

```bash
npm install @yourgpt/llm-sdk@2.6.0-beta.3 @yourgpt/copilot-sdk@2.5.1-beta.3
```

Alternatively, use `@beta` on both package names to follow the beta channel. Install the optional client for your chat provider, such as `openai` or `@anthropic-ai/sdk`. The OpenAI speech/transcription helpers use their own HTTP transport.

## Upgrade behavior to review

- **Anthropic:** a system-role message that was previously ignored by Runtime now takes effect. The effective `systemPrompt` comes first, followed by distinct system instructions. Beta.3 deduplicates text shared by that prompt and a system message, and tolerates null/unsupported non-text system content while preserving valid text.
- **Reasoning models:** the SDK does not silently disable reasoning to honor `temperature`. Use supported `reasoningEffort: 'none'` explicitly when sampling is required. Custom compatible endpoints can opt into passthrough rules.
- **Transport/storage:** `api: 'auto'` keeps compatibility routing. Select Responses explicitly when needed, and choose `store` deliberately. Persist reduced continuation metadata and native tool output when replaying conversations; display text alone is insufficient. Remove top-level Runtime billing `usage` and debug `events` at your application's public response boundary after accounting.
- **Image tools:** ordinary JSON results and the screenshot attachment path retain their behavior. Native image results require a compatible endpoint. Image input to a model and image output from a tool use different content shapes.
- **Audio:** TTS/STT are separate from chat streaming. The recorder does not automatically send a chat message. Keep the transcript editable before submission.

## Validation and production preparation

The isolated beta.3 hotfix passed **371 automated tests on Node 18 and Node 26**, SDK builds/type checks, 22 live OpenAI/Anthropic/OpenRouter checks, 41 packed-consumer regressions and all 13 public entry-point imports. The downloaded npm archive matched the tested release archive. [Post-merge GitHub CI](https://github.com/YourGPT/copilot-sdk/actions/runs/39041171884) and the docs/playground deployments passed. The previous image/audio beta validation remains recorded separately; Google, xAI and Fireworks compatibility paths used transport fixtures rather than live credentials.

Live media checks covered inline images and WAV/MP3 audio; other supported media representations have fixture coverage. Prompt delivery checks do not guarantee strict JSON formatting or application-level guardrail accuracy.

Before promoting your application, validate its actual provider/model combinations, structured-output parsing, persisted-history reloads, and microphone targets. The beta release itself did not promote npm `beta` to `latest` or deploy your backend.
