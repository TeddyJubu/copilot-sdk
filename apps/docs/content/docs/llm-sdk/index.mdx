Use a common generation API with OpenAI, Anthropic, Google, and other supported providers. Model parameters, native tools, caching, and audio support vary by provider. See the [2.6.0 upgrade guide](/docs/release-2-6) for new APIs and compatibility limits.

Check [package versions and compatibility](/docs/llm-sdk/beta-upgrade) when
installing the SDK. The [Feature Lab guide](/docs/feature-lab) explains how to
try each feature and what has been verified with real provider calls.

```ts
import { streamText } from "@yourgpt/llm-sdk";
import { openai } from "@yourgpt/llm-sdk/openai";

const result = await streamText({
  model: openai("gpt-4o"),
  prompt: "Hello!",
});
```

## Framework Examples

Works with any HTTP framework. Returns standard Web `Response` objects.

<Tabs items={['Next.js', 'Express', 'Hono', 'Fastify']}>
  <Tab value="Next.js">
    ```ts title="app/api/chat/route.ts"
    import { streamText } from '@yourgpt/llm-sdk';
    import { openai } from '@yourgpt/llm-sdk/openai';

    export async function POST(req: Request) {
      const { messages } = await req.json();

      const result = await streamText({
        model: openai('gpt-4o'),
        messages,
      });

      return result.toTextStreamResponse();
    }
    ```

  </Tab>
  <Tab value="Express">
    ```ts title="server.ts"
    import express from 'express';
    import { streamText } from '@yourgpt/llm-sdk';
    import { openai } from '@yourgpt/llm-sdk/openai';

    const app = express();
    app.use(express.json());

    app.post('/api/chat', async (req, res) => {
      const result = await streamText({
        model: openai('gpt-4o'),
        messages: req.body.messages,
      });

      const response = result.toTextStreamResponse();
      res.set(Object.fromEntries(response.headers));
      response.body?.pipeTo(new WritableStream({
        write(chunk) { res.write(chunk); },
        close() { res.end(); }
      }));
    });
    ```

  </Tab>
  <Tab value="Hono">
    ```ts title="src/index.ts"
    import { Hono } from 'hono';
    import { streamText } from '@yourgpt/llm-sdk';
    import { openai } from '@yourgpt/llm-sdk/openai';

    const app = new Hono();

    app.post('/api/chat', async (c) => {
      const { messages } = await c.req.json();

      const result = await streamText({
        model: openai('gpt-4o'),
        messages,
      });

      return result.toTextStreamResponse();
    });

    export default app;
    ```

  </Tab>
  <Tab value="Fastify">
    ```ts title="server.ts"
    import Fastify from 'fastify';
    import { streamText } from '@yourgpt/llm-sdk';
    import { openai } from '@yourgpt/llm-sdk/openai';

    const app = Fastify();

    app.post('/api/chat', async (req, reply) => {
      const result = await streamText({
        model: openai('gpt-4o'),
        messages: req.body.messages,
      });

      const response = result.toTextStreamResponse();
      reply.headers(Object.fromEntries(response.headers));
      return reply.send(response.body);
    });
    ```

## Core Functions

| Function                                                         | Description                                                   |
| ---------------------------------------------------------------- | ------------------------------------------------------------- |
| [`streamText()`](/docs/llm-sdk/stream-text)                      | Stream responses in real-time                                 |
| [`generateText()`](/docs/llm-sdk/generate-text)                  | Generate complete responses                                   |
| [`tool()`](/docs/llm-sdk/tools)                                  | Define AI-callable functions                                  |
| [Parameters and fallback](/docs/llm-sdk/parameters-and-fallback) | Handle reasoning settings and specific compatibility failures |
| [Responses](/docs/llm-sdk/responses)                             | Preserve OpenAI conversation and tool state                   |
| [Image tool results](/docs/llm-sdk/tool-images)                  | Return native images to supported models                      |
| [`generateSpeech()` / `transcribe()`](/docs/llm-sdk/audio)       | Generate speech and transcribe recorded audio                 |
| [`experimental_decide()`](/docs/llm-sdk/decisions)               | Classify and score state with native decision models          |
| [`generateImage()`](/docs/llm-sdk/image-generation)              | Generate and edit images                                      |
| [Realtime voice](/docs/llm-sdk/realtime)                         | Experimental browser voice calls over WebRTC                  |

## Why Unified?

- **One API** - Learn once, use everywhere
- **Swap providers** - Change one import, keep all your code
- **Type-safe** - Full TypeScript support across all providers
- **Standard responses** - Web `Response` objects work anywhere
