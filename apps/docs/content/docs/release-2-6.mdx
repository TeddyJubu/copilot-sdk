This guide covers the combined SDK features and compatibility fixes in the `2.6.0`
source on `main`, including Decisions, Responses, image tools, audio and realtime
voice. The documentation and playground use this source. Check
[package availability](/docs/llm-sdk/beta-upgrade) before upgrading an npm
installation; merging source and deploying the website do not publish packages.

## Installation

After the stable versions are published:

```bash
npm install @yourgpt/llm-sdk@2.6.0 @yourgpt/copilot-sdk@2.6.0
```

Use matching stable versions when validating the upgrade. The `beta` tag is a separate release channel for subsequent work. Provider clients such as `openai` and `@anthropic-ai/sdk` remain optional dependencies for the corresponding chat adapters.

Until stable publication, use the verified versions `@yourgpt/llm-sdk@2.6.0-beta.3` and `@yourgpt/copilot-sdk@2.5.1-beta.3`.

## Compatibility checks

- **Anthropic instructions:** Runtime uses `systemPrompt`; modern generation uses `system`. System-role messages reach Anthropic. The effective explicit/default prompt comes first, followed by distinct system instructions in order. Text repeated between that prompt and a system message is sent once. Unsupported non-text system content is ignored; valid text is retained.
- **OpenAI parameters:** reasoning requests omit unsupported temperature values with a warning. Use supported `reasoningEffort: 'none'` explicitly when sampling is needed. Custom compatible servers can select passthrough behavior.
- **Continuation:** preserve reduced continuation metadata, native tool output, and matching tool-call IDs in saved history. Raw provider diagnostics are not replay state. At application response boundaries, remove top-level Runtime billing `usage` and debug `events` after accounting. A transcript containing only visible text cannot restore every Responses conversation.
- **Tools:** raw array/object tool results are preserved rather than converted to `[object Object]`; provider content schemas still apply. Malformed Responses calls can trigger configured fallback before output or tool execution begins. Native image tool output requires a supported provider/endpoint. A screenshot with native output does not add a duplicate user-image turn.
- **Audio:** speech and transcription are separate APIs from chat generation. Browser recording returns a transcript for review; it does not submit a chat message automatically.

## Known limits

The hosted YourGPT storage adapter does not yet preserve all Responses/image replay metadata. Use a lossless custom store and test save/reload/continue for those workflows. Physical microphones, browser permission flows, and recorded-container compatibility still require validation on your target devices.

OpenAI is the built-in TTS/STT provider. Live media checks covered inline images and WAV/MP3; other supported formats have fixture coverage. Cache option forwarding is available for OpenAI Responses, while unified cache usage/cost accounting remains pending. See [storage](/docs/server/storage#responses-and-image-result-persistence) and [prompt caching](/docs/advanced/prompt-caching).

Prompt delivery checks do not establish strict JSON output or application guardrail
accuracy. Evaluate your application's schemas and failure policy with representative inputs.
