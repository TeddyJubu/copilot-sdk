## Feature Lab

The playground has focused examples for parameters,
fallback, Decisions, Responses, image tools, system prompts, speech,
transcription, realtime voice and image generation/editing.
Open the [Feature Lab](/playground/features), or follow the
[testing guide](/docs/feature-lab) to run it locally, configure keys and try each example.
