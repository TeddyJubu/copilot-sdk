`codex/production-release`. No push, PR, version bump, or npm publication has occurred.

## Implemented

- `experimental_decide` and typed boolean, choice, and ordered-score questions.
- Native `openaiDecision`, `typesafeDecision`, `openrouterDecision`, and
  `cloudflareDecision` factories. These use the providers' dedicated endpoints.
- Text/JSON state and native image state for OpenAI, Jev, and Cloudflare;
  unsupported OpenRouter image requests fail explicitly.
- Exact answer identity checks, probability and weighted-score validation,
  named refusals, preserved confidence, usage, and original response metadata.
- Abort/timeout support, bounded response reads, sanitized errors, retryability
  hints without automatic retries, and custom fetch support.
- A standalone support-ticket example in the existing skills demo, a package
  guide, and an unreleased documentation page.

Research sources and Vercel release/source pins are in the
[implementation plan](../plans/2026-10-17-next-beta.md). The implementation uses a separate
native model contract; existing chat, Responses, fallback, tool and audio
implementations were not changed.
