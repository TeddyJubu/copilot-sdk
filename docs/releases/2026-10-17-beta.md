# Beta release: LLM SDK 2.6.0-beta.2 and Copilot SDK 2.5.1-beta.3

## LLM SDK

- Preserve Anthropic Runtime system-role instructions in the provider's top-level `system` field. The explicit `systemPrompt` (or runtime default) comes first, followed by system messages in order. Covers `chat`, `generate`, `stream`, `processChat`, and tool continuations. Existing explicit-prompt usage is unchanged; applications sending both forms now apply both. Unsupported non-text system content errors instead of being silently dropped.
- Add explicit OpenAI Chat/Responses transport selection and Responses continuation/replay metadata, including stored previous-response IDs and stateless encrypted reasoning state. Preserve provider state through Runtime and Copilot JSON/SSE history.
- Add typed native image tool results for OpenAI Responses and Anthropic through `toModelOutput` and `_aiContent`. Preserve the original application result. Unsupported image-output endpoints fail explicitly.
- Add `generateSpeech` / `openaiSpeech` and `transcribe` / `openaiTranscription`, with cancellation, media validation, structured errors, and model-specific timestamp/diarization options.

## Copilot SDK

- Preserve image tool results and provider replay metadata through mixed browser/server tool turns, JSON/SSE responses, and restored UI history.
- Add `VoiceRecorder` and `transcribeRecording` for explicit microphone capture, recording limits, cancellation, upload, and a transcript for review. Transcripts are not submitted automatically.
- Preserve accompanying MCP text alongside image content and avoid marking completed streamed image tools as interrupted.

## Validation and limits

The release combines previously validated Responses and multimodal work with the Anthropic fix. The complete local regression suite has 314 tests; the 34 new Anthropic checks also pass on Node 18 and 20. Four live Anthropic decision-token checks cover both system input forms through streaming and non-streaming Runtime calls. Earlier validation includes 12 Responses scenarios and 18 image/audio scenarios with real provider responses.

Physical microphone/device testing, hosted YourGPT storage replay of provider metadata, realtime voice, and image generation remain follow-ups. Only WAV/MP3 speech and inline image results received live media checks; other supported media forms have fixture coverage. Prompt delivery tests do not guarantee strict JSON output or an application's guardrail fallback behavior.

Use the npm `beta` dist-tag for these versions. Publication requires explicit version confirmation; this document records the prepared release, not publication status. The `latest` dist-tags are not part of this release.
