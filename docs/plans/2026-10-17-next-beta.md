## Research before implementation

Checked on 2026-10-17 against official provider documentation and the Vercel AI SDK
source snapshot [`fce9210`](https://github.com/vercel/ai/tree/fce9210c6405c0ad8452fee3f50717e8ea910b97).
The older competitor checkout dated May 2026 predates native Decisions. A fresh
snapshot was downloaded for this work; the old checkout was preserved.

Image details were checked against [Jev image documentation](https://docs.typesafe.ai/images)
and Cloudflare's [input](https://developers.cloudflare.com/workers-ai/models/clef/schema-input.json)
and [output](https://developers.cloudflare.com/workers-ai/models/clef/schema-output.json) schemas.
Jev image support is experimental and needs its image opt-in header; remote image
URLs are not accepted by Jev or Cloudflare. The adapter must not fetch them itself.

### Vercel comparison

- [`@ai-sdk/openai` changelog](https://github.com/vercel/ai/blob/fce9210c6405c0ad8452fee3f50717e8ea910b97/packages/openai/CHANGELOG.md): 4.0.85 native Decisions, 4.0.86 refusal handling, 4.0.89 image state, 4.0.91 image detail. Current 4.0.96 also adds ordered additional tools to Responses; that is separate work.
- [`@ai-sdk/typesafe-ai` changelog](https://github.com/vercel/ai/blob/fce9210c6405c0ad8452fee3f50717e8ea910b97/packages/typesafe-ai/CHANGELOG.md): 3.0.19 image inputs, 3.0.20 reference handling, 3.0.21 box questions.
- [`ai@7.0.143` release](https://github.com/vercel/ai/releases/tag/ai%407.0.143), published October 16: adds box questions. Box detection is additional scope; the first common contract covers boolean, choice, and score.
- Vercel separates `experimental_decide` from chat generation. We will use the same separation and question concepts, preserve returned confidence rather than inventing a confidence score, and validate distributions without renormalizing them.
- Vercel's TypeSafe adapter allows two-decimal rounding when validating probability sums and weighted scores. Apply that tolerance only for confirmed TypeSafe output, including through OpenRouter.
- No native Cloudflare/OpenRouter Decisions adapter was found in the inspected Vercel repository. Those transports are derived from their own official documentation, not claimed as Vercel implementations.

## Implementation and verification plan

1. Add an experimental, typed Decisions API and four independent provider factories.
   Keep chat, Responses, tools, audio, and existing provider factories compatible.
2. Validate JSON state, question types, provider limits, exact answer identities,
   distributions, selected choices, weighted scores, confidence, and refusals.
3. Support image state where the native endpoint documents it. Preserve original
   state and never silently discard unsupported input.
4. Use abortable HTTP with a timeout, sanitized errors and explicit retryability.
   No automatic paid retries, fallback-to-chat, or automatic guardrail migration.
5. Add deterministic wire/error tests, CJS/ESM public type checks, a support-ticket
   example, and opt-in real tests using existing example credentials.
6. Re-run existing compatibility, Responses, image tool, TTS/STT, and Anthropic
   system-message checks. Record live failures separately from local fixture passes.

The published beta already includes Responses conversation state, native image tool
results, OpenAI TTS/STT, parameter/fallback fixes, and Anthropic system prompts.
This branch started with Decisions. The user's subsequent request added realtime
voice and image generation; see the [media beta plan](2026-10-17-media-beta.md).
Broader provider audio, hosted replay, and
other Responses parity items remain separate follow-up work; this plan does not
claim that every provider capability is already implemented.

No version bump, push, PR, or npm publication is part of preparing this branch.
Those operations require the user's separate confirmation under the repository rules.
